Модуль должен агрегировать в себе весь необходимый функционал для наполнения сайта контентом:
    ++ Генерация описаний товаров
        массовая генерация
            ТЗ:
                получать из БД продукты с пустым описанием, но не все а только те которые моложе указанной даты
                    отправлять запрос в GPT с заданным промптом полученный результат записывать в БД  sfly_products.description
                предполагаю что
                    с первого раза промпт не даст удовлетворительного результата
                    результат может быть удовлетворительный для большинства товаров но не для всех
                    результат последней генерации не должен теряться при перезагрузке страницы
                        т.е. при перезагрузке страницы нужно получать данные последней генерации из кеша
                        тогда почему не отобразить все существующие генерации
                        и не предоставить пользователю возможность выбирать какую из них отображать на странице
                по этому считаю необходимым
                    при каждой генерации кешировать
                        id товаров для которых было сгенерировано описание
                        модель которая была использована
                        количество использованных токенов
                        само описание, хотя, не уверен что это действительно нужно, но пока на всякий случай
                    основная цель кеширования
                        понять описания каких именно товаров были сгенерированы для того что бы перегенерировать их
                        пока только это
                    реализовать механизм исключения / добавления товаров в список тех для которых нужно генерировать описания в // TODO
            Реализация:
                в папке модуля папка cache генераций
                    в этой папке cache json файлы в названии которых явно указана дата генерации с точностью до минуты
                структура данных:
                    {
                        "generated_at": "2025-01-09 10:42",
                        "task": "product_description",
                        "model": "gpt-4.1-mini",
                        "results": {}
                    }
            Описание использования:
                в интерфейсе
                    ++ поле для ввода даты (товары созданные до введённой даты не обрабатываются)
                    ++ поле для ввода промпта '%product_name%' - строка шаблон в место неё будет подставлено название товара
                    поле для ввода id товаров которые нужно обработать
                    +- кнопка "Отправить сгенерированные описания в базу данных"
                    поле куда выводится список всех закешированных генераций
                    ++ поле в которое выводится лог обработки
                        id товара
                        название товара
                        сгенерированное описание
                        количество токенов потраченных на данное описание
                        результат добавления в БД
                алгоритм
                    если дата не выбрана  кнопка запуска не активна обработка не начнётся
                    если промпта нет  кнопка запуска не активна обработка не начнётся
                    если в промпте нет '%product_name%' кнопка запуска не активна обработка не начнётся
                    если поле для ввода id товаров пусто будет запущена обработка всех товаров моложе указанной даты
